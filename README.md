# 카페 벨로라 홈페이지

바로크풍 유럽 살롱에서 영감을 받은 카페 소개 홈페이지입니다. 별도의 프레임워크나 빌드 도구 없이 `index.html` 하나로 구성되어 있습니다.

## 실행 방법

`index.html` 파일을 웹 브라우저에서 열면 됩니다. 별도의 패키지 설치나 서버 실행은 필요하지 않습니다.

## 주요 기능

- 바로크풍 색상과 장식, 카페 공간을 담은 반응형 화면
- 커피, 티·음료, 디저트 메뉴 6종과 종류별 필터
- 예약 창에서 방문 날짜와 인원을 입력하는 프런트엔드 데모
- 현재 연도 표시와 모바일 화면 대응

## 파일 구성

```text
week11/
├── index.html  # 홈페이지, CSS, JavaScript
├── README.md   # 프로젝트 설명
└── hello.js    # Git 실습용 파일
```

## 참고 사항

화면의 사진은 Unsplash, 글꼴은 Google Fonts에서 불러옵니다. 해당 리소스를 표시하려면 인터넷 연결이 필요합니다. 예약 폼은 입력 확인 메시지만 보여주는 데모이며, 실제 예약 저장이나 전송 기능은 연결되어 있지 않습니다.
